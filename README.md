# Vuokra vai oma Oulussa

Selainlaskuri, joka vertaa kahta vaihtoehtoa:

1. Myy talo, asu vuokralla ja sijoita koko myyntisumma.
2. Osta velaton asunto ja sijoita loput.

Laskuri näyttää rajavuokran (vuokra, jolla vaihtoehdot ovat tasoissa), kuukausittaisen rahavirran ja nettovarallisuuden kehityksen valitulle ajalle. Kaikki oletukset ovat muokattavissa, ja sivun lopussa on selitykset termeille ja laskentaperiaatteille.

Laskuri on yksi staattinen `index.html`-tiedosto ilman riippuvuuksia (fontit Google Fontsista).

Laskelmat ovat suuntaa antavia, eivät sijoitusneuvontaa.
